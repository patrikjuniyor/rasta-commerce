# ارزیابی آمادگی راستا کامرس برای فروش در راست چین

**تاریخ بررسی:** ۱۴۰۵/۰۵/۱۳ (۲۰۲۶/۰۸/۰۴)
**نسخه بررسی‌شده:** Rasta Commerce 1.4.1 / Rasta ZarinPal Gateway 1.0.1
**نتیجه:** **هنوز برای ارسال به راست چین آماده نیست.** کد محصول و بستهٔ نصب‌پذیر وضعیت خوبی دارند، اما الزامات عرضه، دمو، مستندات و استانداردهای ویژهٔ مارکت‌پلیس کامل نشده‌اند.

> این ارزیابی بر اساس صفحه‌های عمومی «استاندارد ارسال محصول»، «استاندارد فارسی‌سازی» و «راهنمای آیکون و کاور» راست چین انجام شده است. این قوانین ممکن است تغییر کنند؛ پیش از ارسال باید دوباره بررسی شوند.

## موارد مسدودکنندهٔ ارسال

### 1. پکیج استاندارد فروشگاه

راست چین برای قالب وردپرس ساختار مشخصی می‌خواهد:

```text
Rasta-Commerce-RTLTheme/
├── Theme/
│   ├── rasta-commerce-1.4.1.zip
│   └── rasta-commerce-child.zip       # پیشنهاد جدی؛ در صورت ارائهٔ child theme
├── Plugins/
│   └── rasta-zarinpal-gateway-1.0.1.zip
├── Import Files/                       # اختیاری، ولی برای importer توصیه می‌شود
└── help.pdf                            # راهنمای فارسی الزامی
```

وضعیت فعلی: اسکریپت `npm run marketplace:prepare` این ساختار را با قالب اصلی، child theme، افزونه ضروری، WXR و `help.pdf` می‌سازد. خروجی نهایی عمداً تا زمان اضافه شدن فایل‌های دموی واقعی و دارایی‌های ثبت محصول قفل می‌ماند.

### 2. دمو فارسی واقعی و نصب آسان

دموی HTML موجود برای معرفی ظاهری خوب است، ولی جای دموی واقعی WordPress را نمی‌گیرد. باید:

- یک دامنه یا زیردامنهٔ اختصاصی با دموی فارسی کامل راه‌اندازی شود.
- WooCommerce، محصولات نمونه، منوها، صفحه‌ها، تنظیمات Customizer و افزونه ضروری روی آن فعال باشند.
- بستهٔ Duplicator شامل `installer.php` و archive ساخته شود.
- دو فایل Duplicator بدون پوشهٔ تو‌در‌تو در ZIP دموی ارسالی قرار بگیرند.
- مشتری بتواند پس از نصب، دقیقاً همان دموی فارسی را بالا بیاورد.

### 3. راهنمای PDF فارسی

`marketplace/help.pdf` فارسی ساخته شده و source آن در `marketplace/help-source.html` قرار دارد. راهنما شامل نیازمندی‌ها، نصب، Duplicator، child theme، Customizer، WooCommerce، زرین‌پال، آپدیت و رفع خطاهای رایج است.

پیش از ارسال نهایی باید فقط یک بار با دموی واقعی و نسخه نهایی محصول بازبینی شود؛ هیچ لینک تماس شخصی نباید در دمو، پکیج یا PDF قرار گیرد.

### 4. کاور، آیکون و محتوای فروش

باید مستقل از `screenshot.png` فنی پروژه آماده شوند:

- آیکون 320×320 با عنوان فارسی و بدون screenshot یا شماره نسخه
- کاور افقی 2100×1040
- 5 تا 8 اینفوگرافی خوانا از امکانات کلیدی
- اسکرین‌شات‌های واقعی از دموی WordPress
- یک پالت و فونت یکسان در کاور، آیکون، اینفوگرافی و لندینگ

طبق راهنمای راست چین، خروجی مستقیم AI برای کاور و تصاویر معرفی قابل پذیرش نیست؛ بنابراین باید این دارایی‌ها توسط طراح گرافیک و از اسکرین‌شات دموی واقعی ساخته شوند.

### 5. صفحه‌ساز و ویجت‌ها

مسیر **Elementor** انتخاب و افزونه همراه `Rasta Commerce Core for Elementor` ساخته شد. این افزونه ۱۰ ویجت فارسی دارد: Hero، Section Heading، Product Grid، Product Rail، Category Grid، Promo Banner، Trust Strip، Blog Grid، Feature Card و FAQ.

موارد باقی‌مانده:

1. Elementor و WooCommerce روی staging واقعی نصب و هر ۱۰ ویجت در editor، frontend، موبایل و RTL تست شوند.
2. یک دموی واقعی Elementor با همین ویجت‌ها ساخته و با Duplicator صادر شود.
3. از راست چین درباره پذیرش این مسیر و نحوه لایسنس/آپدیت افزونه Core تأیید نهایی گرفته شود.

## موارد مهم با اولویت بالا

1. **فونت ایرانی با مجوز روشن:** انجام شد؛ Vazirmatn با مجوز OFL در `assets/fonts/` بسته‌بندی شده است.
2. **تاریخ جلالی:** انجام شد؛ تاریخ‌های خروجی قالب و دیدگاه‌ها Jalali شده و تست قرارداد دارند. تاریخ‌های افزونه‌های ثالث باید در staging بررسی شوند.
3. **child theme:** انجام شد؛ source و اسکریپت ZIP child theme اضافه شده است.
4. **فایل ترجمه:** انجام شد؛ فایل‌های POT برای قالب و افزونه زرین‌پال تولید شده‌اند.
5. **تست روی محیط واقعی:** نصب تازهٔ WordPress + WooCommerce، نصب ZIP، نصب افزونه زرین‌پال، درون‌ریزی دمو، موبایل، Firefox/Chrome/Safari، سبد، checkout و callback Sandbox باید مستند شوند.
6. **زرین‌پال:** برای فروش، راهنمای تنظیم Merchant ID و تست Sandbox آماده است؛ اما تراکنش واقعی فقط در staging با Merchant ID فروشنده و دامنهٔ تاییدشده قابل تأیید نهایی است.
7. **VirusTotal:** پس از ساخت پکیج نهایی راست چین، ZIP نهایی باید اسکن و نتیجه ثبت شود.
8. **نام و یکتایی محصول:** جست‌وجو یک محصول موجود با نام «قالب HTML فروشگاهی رستا» را نشان می‌دهد. هرچند محصول ما WordPress است و نام «راستا کامرس» دارد، شباهت برند ریسک رد یا درخواست تغییر نام دارد؛ قبل از رزرو باید از راست چین استعلام گرفته شود یا نام تجاری کاملاً متمایز انتخاب شود.
9. **مالکیت و یکتایی:** پیش از رزرو نام، نبود محصول مشابه در راست چین بررسی شود. برای محصول بومی، یک فایل مالکیت/منشأ کد و دارایی‌ها نگه‌داری شود؛ `Original Version` مربوط به محصولات ترجمه‌شدهٔ LTR است و برای محصول بومی نباید ساختگی تولید شود.
10. **لایسنس و آپدیت:** پیش از فروش باید مشخص شود لایسنس و به‌روزرسانی راست چین چگونه به قالب و افزونه همراه متصل می‌شود.

## نقاط قوت فعلی

- معماری درست جداسازی قابلیت‌های پرداخت از قالب.
- RTL و فارسی native با استفاده از logical properties.
- WooCommerce integration، کنترل‌های خرید و UI حرفه‌ای.
- CI، نسخه‌بندی، changelog و ZIPهای نصب‌پذیر.
- callback زرین‌پال با تطبیق Authority و order key، verify سمت سرور و عدم ثبت دادهٔ حساس کارت.
- مستندات فنی و راهنمای افزونه در مخزن.

## ترتیب پیشنهادی برای رسیدن به نسخهٔ قابل ارسال

1. دریافت تأیید راست چین دربارهٔ مسیر Gutenberg یا توسعهٔ بسته Elementor + ۱۰ ویجت.
2. ساخت child theme، فونت مجاز و جلالی‌سازی.
3. ساخت دموی فارسی کامل و بسته Duplicator در staging.
4. ساخت PDF راهنمای فارسی.
5. طراحی انسانی کاور، آیکون و اینفوگرافی بر پایه screenshotهای دموی واقعی.
6. تولید پکیج استاندارد راست چین و اجرای تست نصب از صفر.
7. تست Sandbox زرین‌پال با Merchant ID/UUID و ثبت نتیجه.
8. VirusTotal، رزرو نام محصول، تکمیل صفحه فروش، ارسال برای بررسی.
