# Rasta Commerce Core for Elementor

افزونه همراه راستا کامرس برای ساخت صفحه‌های فروشگاهی با Elementor. این افزونه 10 ویجت RTL-native در دسته «راستا کامرس» اضافه می‌کند:

1. هیرو فروشگاه
2. تیتر بخش
3. شبکه محصولات
4. ریل محصولات
5. دسته‌بندی محصولات
6. بنر تبلیغاتی
7. نوار اعتماد
8. شبکه مجله
9. کارت ویژگی
10. پرسش‌های متداول

## نصب

1. Elementor و قالب Rasta Commerce را نصب و فعال کنید.
2. فایل `rasta-commerce-core-1.0.0.zip` را از مسیر **افزونه‌ها ← افزودن ← بارگذاری افزونه** نصب کنید.
3. یک برگه را با Elementor ویرایش کنید.
4. از دسته «راستا کامرس» ویجت‌ها را به برگه بکشید.

## نکات

- ویجت‌های محصول و دسته‌بندی به WooCommerce نیاز دارند.
- هر ویجت کنترل‌های محتوایی، query و استایل پایه دارد.
- این افزونه برای بازتولید دموهای Elementor طراحی شده و جایگزین قابلیت‌های اصلی قالب نیست.
- پیش از فروش نهایی، همه ویجت‌ها باید روی نسخه واقعی Elementor و WooCommerce در staging تست شوند.
