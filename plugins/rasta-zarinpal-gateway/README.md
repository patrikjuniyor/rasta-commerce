# درگاه زرین‌پال راستا برای WooCommerce

این افزونه‌ی مستقل، پرداخت زرین‌پال API v4 را به WooCommerce اضافه می‌کند. به‌صورت عمدی خارج از ZIP قالب نگه‌داری شده تا با تغییر قالب، تنظیمات پرداخت و سفارش‌ها پایدار بمانند.

## نصب

1. فایل `rasta-zarinpal-gateway-1.0.1.zip` را از Release پروژه دریافت کنید.
2. در WordPress به **افزونه‌ها ← افزودن ← بارگذاری افزونه** بروید و افزونه را فعال کنید.
3. از **WooCommerce ← تنظیمات ← پرداخت‌ها ← زرین‌پال** روی «مدیریت» بزنید.
4. Merchant ID زرین‌پال را وارد، درگاه را فعال و واحد مبلغ را بررسی کنید.
5. ابتدا Sandbox را با یک UUID آزمایشی امتحان کنید؛ سپس Sandbox را غیرفعال و Merchant ID تولیدی زرین‌پال را وارد کنید.

## نکات امنیتی

- Merchant ID در تنظیمات مدیریت WordPress ذخیره می‌شود و در frontend چاپ نمی‌شود.
- callback با کلید سفارش و Authority ذخیره‌شده تطبیق داده می‌شود.
- پرداخت تنها بعد از verify سمت سرور و کدهای موفق ۱۰۰ یا ۱۰۱ کامل می‌شود.
- شماره کارت و `card_hash` در سفارش یا log ذخیره نمی‌شود.
- برای فروش واقعی، سایت باید HTTPS، دامنه‌ی تأییدشده و افزونه‌های به‌روز داشته باشد.

## واحد پول

زرین‌پال در API v4 از `IRR` و `IRT` پشتیبانی می‌کند. حالت «خودکار» ارز فعلی WooCommerce را استفاده می‌کند؛ در صورت تفاوت ریال/تومان، تبدیل ۱۰ برابری انجام می‌شود.
