# Rasta Commerce Child

این child theme برای تغییرات امن CSS و PHP در راستا کامرس است.

1. ابتدا قالب اصلی `rasta-commerce` را نصب و فعال کنید.
2. سپس این ZIP را از مسیر **نمایش ← پوسته‌ها ← افزودن پوسته ← بارگذاری پوسته** نصب کنید.
3. child theme را فعال کنید.
4. CSS سفارشی را در `style.css` و hookهای PHP را در `functions.php` وارد کنید.

به‌روزرسانی قالب اصلی، تغییرات داخل child theme را حذف نمی‌کند.
