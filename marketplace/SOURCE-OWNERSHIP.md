# منشأ کد و دارایی‌ها

## راستا کامرس

- کد قالب، CSS، JavaScript، ساختار WooCommerce، مستندات و اسکریپت‌های build در این مخزن توسعه داده شده‌اند.
- تصویرسازی `assets/images/hero-showcase.svg` و screenshot فنی صرفاً دارایی‌های محصول برای نمایش ساختار UI هستند.
- قبل از ارسال به راست چین، کاور، آیکون و اینفوگرافی باید توسط طراح انسانی و بر پایه دموی واقعی ساخته و مالکیت آن‌ها مستند شود.

## وابستگی‌های دارای مجوز

- **Vazirmatn**: در `assets/fonts/` همراه با `OFL-Vazirmatn.txt` قرار دارد و تحت SIL Open Font License 1.1 منتشر شده است.
- **WordPress** و **WooCommerce**: وابستگی‌های بیرونی کاربر هستند و در پکیج محصول کپی نشده‌اند.

## مواردی که نباید در پکیج ثبت محصول قرار گیرند

- Merchant ID، رمزها، API keyها، فایل‌های `wp-config.php`، database dump دارای داده واقعی یا اطلاعات دسترسی.
- archive دموی واقعی تا زمانی که اطلاعات نمونه، مجوز رسانه‌ها و داده‌های حساس آن بازبینی نشده‌اند.
- فایل‌های AI-generated برای کاور و تصاویر معرفی راست چین.
