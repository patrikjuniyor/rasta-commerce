# محتوای آغازین راستا کامرس

فایل `rasta-commerce-starter.xml` یک WXR سبک شامل برگه خانه، یک مقاله و سه محصول فارسی نمونه است.

## روش استفاده

1. WooCommerce و قالب راستا کامرس را فعال کنید.
2. افزونه رایگان **WordPress Importer** را از بخش ابزارها ← درون‌ریزی نصب کنید.
3. فایل XML را انتخاب و نویسنده را بسازید یا به کاربر فعلی تخصیص دهید.
4. از بخش تنظیمات ← خواندن، برگه «خانه» را به‌عنوان برگه نخست ایستا انتخاب کنید.
5. محصولات را با تصاویر، ویژگی‌ها، موجودی و دسته‌بندی واقعی خود تکمیل کنید.

> این WXR برای شروع سریع است و **جایگزین بسته Duplicator دموی کامل نیست**. برای ارسال به راست چین باید بسته نصب آسان دموی واقعی نیز ساخته شود.
