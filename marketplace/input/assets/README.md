# دارایی‌های ثبت محصول

دارایی‌های زیر باید توسط طراح گرافیک انسانی و بر پایه screenshotهای دموی واقعی ساخته شوند:

- `icon-320x320.png`
- `cover-2100x1040.jpg` یا `cover-2100x1040.png`
- حداقل 5 اینفوگرافی معرفی ویژگی‌ها

راست چین استفاده از خروجی مستقیم AI برای کاور و تصاویر معرفی را نمی‌پذیرد. این دارایی‌ها را در Git قرار ندهید مگر مالکیت و مجوز استفاده آن‌ها کاملاً روشن باشد.
