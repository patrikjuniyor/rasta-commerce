راهنمای راه‌اندازی راستا کامرس

قالب فروشگاهی RTL-first برای WordPress و WooCommerce

نسخه قالب: 1.4.0 یا جدیدتر
نسخه افزونه زرین‌پال: 1.0.1 یا جدیدتر
WordPress: 6.4 یا جدیدتر
PHP: 8.0 یا جدیدتر
پیش از شروع: از سایت فعلی نسخه پشتیبان کامل بگیرید. نصب آسان فقط برای راه‌اندازی سایت تازه توصیه می‌شود.

1. محتویات پکیج

  • Theme: فایل rasta-commerce-1.4.0.zip برای نصب قالب اصلی و در صورت ارائه فایل child theme.
  • Plugins: افزونه‌های ضروری قالب؛ از جمله افزونه مستقل درگاه زرین‌پال در صورت نیاز.
  • Import Files: فایل‌های درون‌ریزی یا بسته نصب آسان دمو.
  • help.pdf: همین راهنمای فارسی.

2. نصب قالب

  1. وارد پیشخوان WordPress شوید.
  2. به نمایش ← پوسته‌ها ← افزودن پوسته ← بارگذاری پوسته بروید.
  3. فایل rasta-commerce-1.4.0.zip را انتخاب، نصب و فعال کنید.
  4. افزونه WooCommerce را نصب و فعال کنید.
  5. از نمایش ← فهرست‌ها یک فهرست بسازید و آن را به جایگاه «منوی اصلی» اختصاص دهید.

استفاده از child theme

اگر می‌خواهید CSS یا hookهای PHP را تغییر دهید، ابتدا قالب اصلی و سپس child theme را نصب کنید و child theme را فعال نمایید. این کار باعث می‌شود تغییرات شما هنگام آپدیت قالب اصلی حذف نشوند.

3. نصب آسان و درون‌ریزی دمو

در صورت دریافت بسته Duplicator، فایل installer.php و archive دمو را در ریشه هاست یک دامنه یا زیردامنه خالی قرار دهید و سپس آدرس https://your-domain/installer.php را باز کنید.

  • برای cPanel از راهنمای رسمی: نصب آسان در cPanel
  • برای DirectAdmin از راهنمای رسمی: نصب آسان در DirectAdmin
  • برای localhost از راهنمای رسمی: نصب آسان در localhost
هشدار: بسته نصب آسان اطلاعات پایگاه‌داده مقصد را جایگزین می‌کند. روی سایت فعال یا فروشگاه دارای سفارش از آن استفاده نکنید.

4. شخصی‌سازی ویترین

به نمایش ← سفارشی‌سازی بروید.

بخشکاربرد
ویترین راستارنگ اصلی و ثانویه، نوار اطلاع‌رسانی، متن و تصویر هیرو، شبکه‌های اجتماعی
ابزارهای خرید راستانمایش سریع، مقایسه، علاقه‌مندی، محصولات اخیراً دیده‌شده، sticky cart، شمارش‌گر تخفیف و آستانه ارسال رایگان
WooCommerceواحد پول، مالیات، حمل‌ونقل، پرداخت و تصاویر محصول

5. تنظیم WooCommerce

  1. از WooCommerce ← تنظیمات ← عمومی واحد پول و نشانی فروشگاه را تنظیم کنید.
  2. از بخش محصولات دسته‌بندی، ویژگی، موجودی و تصویر محصولات را وارد کنید.
  3. برای نمایش صحیح هشدار موجودی پایین، گزینه مدیریت موجودی را برای محصول فعال کنید.
  4. برای شمارش‌گر تخفیف، در اطلاعات محصول تاریخ پایان فروش ویژه تعیین کنید.
  5. برای نوار ارسال رایگان، مبلغ حداقل را از بخش «ابزارهای خرید راستا» وارد کنید.

6. ساخت صفحه با Elementor

  1. Elementor و افزونه rasta-commerce-core-1.0.0.zip را نصب و فعال کنید.
  2. یک برگه جدید بسازید و دکمه «ویرایش با Elementor» را انتخاب کنید.
  3. از دسته «راستا کامرس» ویجت Hero، Product Grid، Product Rail، Category Grid، Promo Banner، Trust Strip، Blog Grid، Feature Card و FAQ را به برگه اضافه کنید.
  4. برای ویجت‌های محصول و دسته‌بندی، WooCommerce و داده نمونه لازم است.
  5. پس از ساخت صفحه، نمایش desktop، mobile و RTL را بررسی کنید.

7. راه‌اندازی درگاه زرین‌پال

  1. فایل rasta-zarinpal-gateway-1.0.1.zip را از افزونه‌ها ← افزودن ← بارگذاری افزونه نصب و فعال کنید.
  2. به WooCommerce ← تنظیمات ← پرداخت‌ها ← زرین‌پال بروید.
  3. Merchant ID را وارد کنید، عنوان درگاه را بررسی و درگاه را فعال کنید.
  4. ابتدا گزینه Sandbox را فعال کنید و با UUID آزمایشی تست کنید.
  5. پس از تأیید، Sandbox را خاموش و Merchant ID واقعی زرین‌پال را وارد کنید.

درگاه پیش از کامل کردن سفارش، Authority بازگشتی را با سفارش تطبیق می‌دهد و verify سمت سرور انجام می‌دهد. شماره پیگیری زرین‌پال در صفحه تشکر و یادداشت سفارش نمایش داده می‌شود.

8. به‌روزرسانی امن

  1. از فایل‌ها و پایگاه‌داده نسخه پشتیبان بگیرید.
  2. تغییرات اختصاصی را در child theme نگه‌داری کنید.
  3. نسخه جدید قالب یا افزونه را از بخش دانلودهای راست چین دریافت کنید.
  4. پس از آپدیت، cache را پاک و صفحات فروشگاه، سبد، پرداخت و حساب کاربری را تست کنید.
  5. درگاه زرین‌پال را ابتدا با یک سفارش Sandbox یا کم‌مبلغ بررسی کنید.

9. رفع خطاهای متداول

مشکلراه‌حل
دمو کامل نمایش داده نمی‌شودنسخه PHP، محدودیت حافظه، permalinks و فعال بودن WooCommerce را بررسی کنید؛ سپس درون‌ریزی را روی سایت تازه تکرار کنید.
زرین‌پال در پرداخت نمایش داده نمی‌شودMerchant ID، فعال بودن درگاه، واحد پول IRR/IRT و فعال بودن WooCommerce را بررسی کنید.
بازگشت از پرداخت ناموفق استHTTPS، permalinkها، دامنه مورد تأیید زرین‌پال و لاگ WooCommerce را بررسی کنید.
استایل تغییر کرده استcache مرورگر و افزونه cache را پاک کنید؛ در صورت وجود minify، فایل‌های CSS/JS قالب را از ترکیب نادرست مستثنا کنید.
